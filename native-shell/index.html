Réglages imprimante

Configure l'imprimante ticket réseau (ESC/POS, port RAW 9100) utilisée par cette caisse. Ces réglages sont mémorisés sur l'appareil.

    Aide à l'installation
    
    
      
  1. Branche l'imprimante en Ethernet (ou Wi-Fi) sur le même réseau que l'iPad.
    2. 
      
  2. Donne-lui une IP fixe : IP statique sur l'imprimante, ou réservation DHCP par adresse MAC sur la box. Sinon l'IP change et la caisse perd l'imprimante.
    3. 
      
  3. Imprime l'auto-test réseau (souvent maintenir FEED à l'allumage) pour lire l'IP. Vérifie que le port 9100 RAW / JetDirect est activé.
    4. 
      
  4. Saisis l'IP ci-dessus, teste la connexion puis imprime un ticket test avant d'enregistrer.
